# Research notes

Checked 2026-11-04.

- Oracle publishes no price for Argus. Oracle's own product page for Argus Enterprise Edition says it is licensed "based on case license metric rather than user metric", on premise or as a cloud service. The cloud documentation describes a Usage Billing tool that counts new cases against the subscription, and two cloud tiers, Argus Basic Cloud Service and Argus Advanced Cloud Service. Sources: https://www.oracle.com/pl/corporate/accessibility/templates/t2-3551.html and https://docs.oracle.com/en/industries/life-sciences/argus-safety/8.4.4/acadm/usage-billing.html
- Smaller sponsors often rent Argus access through a service provider instead of licensing it (CMIC in Japan sells case processing plus database access, or the database alone). Source: https://blogs.oracle.com/life-sciences-jp/argus-safety-jp-customer-story-cmic
- Reporting deadlines in docs/compliance.md were read on tga.gov.au and medsafe.govt.nz on the same date.
